# Web 弹幕控制台美化设计

## 目标
- 解决弹幕列表占满整屏、层级混乱的问题。
- 保持现有 FastAPI/SSE 接口和数据契约不变。
- 使用深色“直播间控制台”风格：玻璃面板、清晰分区、彩色分类胶囊、可读性优先。

## 范围
- 仅修改 `static/index.html`。
- 增加浏览器 UI 冒烟测试 `tests/ui_smoke.spec.js`，验证弹幕面板有滚动边界且页面无横向溢出。

## 方案对比
1. 仅调 CSS 高度：改动最小，但信息层级和控件仍杂乱。
2. 重排为固定页头 + 主工作区 + 右侧控制栏：兼顾美观、可读性和操作性（选定）。
3. 拆分多文件/引入 UI 框架：超出当前小改动范围。

## 实现要点
- 页面使用 `100dvh` 的 grid shell；页头固定，内容区不撑破视口。
- 热门房间压缩为水平滚动卡片；筛选、状态和会话操作进入右栏。
- 弹幕流成为主区域卡片，内部滚动，最多保留 300 条，避免无上限 DOM。
- 保留原有点击房间、SSE、分类过滤、导出/历史功能。
